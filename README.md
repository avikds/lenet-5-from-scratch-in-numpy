# lenet-5-from-scratch-in-numpy
Gradient-Based Learning Applied to Document Recognition (LeCun, Bottou, Bengio and Haffner, 1998), rebuilt in NumPy with every gradient written by hand. Build the paper's LeNet-5 exactly as it describes it: a 32 x 32 input scaled so the background is -0.1 and the ink is 1.175, the squashing function 1.7159 tanh(2a/3), convolution layers C1, C3…
